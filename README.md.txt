🚀 Excited to share my latest DevOps project: Infrastructure Monitoring & Visualization on AWS EC2!

Deploying an application is just the beginning. Monitoring its performance and ensuring its availability are equally important. 🔍

In this project, I used Prometheus and Grafana on AWS EC2 to monitor server health, track resource usage, and visualize performance metrics.

🔧 Project Implementation Steps:
Launch AWS EC2 Instance – Created an EC2 instance to host the monitoring setup.
Install Prometheus – Set up Prometheus to collect and store system metrics.
Configure Node Exporter – Collected server-level metrics such as CPU, memory, disk, and network usage.
Install Grafana – Set up Grafana to visualize the collected metrics.
Connect Prometheus with Grafana – Configured Prometheus as a data source in Grafana.
Create Monitoring Dashboards – Built dashboards to track infrastructure performance in real time.
Configure Website Monitoring – Added website availability checks to understand uptime and response times.
Analyze Performance – Used dashboards to identify resource usage patterns and potential performance issues.
💡 Key Learnings:
AWS EC2 infrastructure management
Prometheus metrics collection
Grafana dashboard creation
Server and website monitoring
Basic troubleshooting and observability

This project helped me understand how monitoring improves infrastructure visibility and makes troubleshooting easier.
